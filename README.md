## ◈ Who I Am

```
🎓  B.Tech Computer Science     Thapar Institute of Engineering & Technology
🧠  Core focus                  Retrieval-Augmented Generation · LLM security · agentic systems
🔐  Working thesis               Grounding LLMs in retrieved evidence makes them both more
                                  accurate AND more explainable — and the same retrieval
                                  layer is where you catch the system trying to attack itself
🎯  Right now                    Pursuing ML/AI internship roles
```

> **I don't just fine-tune models — I build the retrieval, evaluation, and defense layers around them.**

> a decision, and can it survive someone actively trying to break it?
